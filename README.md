# 2048

零依赖纯前端 2048。打开 `index.html` 就能玩，键盘方向键 / WASD，手机端滑动，支持撤销与最高分本地保存。

## 玩法与规则

- 4×4 棋盘，初始两个数字块（2 或 4）。
- 每次移动后新增一个块：90% 是 2，10% 是 4。
- 相同数字相撞合并成两倍，得分即合并后的数值；一次移动里每个块最多合并一次。
- 棋盘填满且四个方向都无法移动时游戏结束；合成到 2048 弹出达成提示，可以继续打更高。

## 结构

| 文件 | 职责 |
| --- | --- |
| `game.js` | 纯逻辑，零 DOM 依赖：压缩合并、四向移动、生成新块、终局判定。浏览器挂到 `window.TwentyFortyEight`，Node 下 `module.exports` |
| `ui.js` | 渲染、键盘与触摸输入、撤销栈、最高分存储 |
| `index.html` | 页面结构 |
| `style.css` | 样式与出现/合并动画 |
| `test/game.test.mjs` | 逻辑测试，`node --test` 之外的极简断言运行器，无依赖 |

## 跑测试

```bash
node test/game.test.mjs      # 或 npm test
```

全部通过时逐行打印 `ok`，退出码 0；任一失败打印 `FAIL` 并以非零码退出。

## 本地预览

直接双击 `index.html`，或起一个静态服务器：

```bash
python -m http.server 2048 --bind 127.0.0.1
# 打开 http://127.0.0.1:2048
```
